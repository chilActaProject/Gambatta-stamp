# Gambatta-stamp
# 「がんばった すたんぷ」 — シンプル版

子どもたちの頑張りをスタンプで記録できるアプリです。

## 📦 ファイル構成

```
index.html       ← メインのアプリファイル（これをダウンロード・配布します）
GUIDE.md         ← ユーザー向けの使い方ガイド
DISTRIBUTE.md    ← Note配布時のテンプレート・チェックリスト
README.md        ← このファイル
```

## 🚀 クイックスタート

### 1. ファイルの確認
すべてのファイルが揃っていることを確認してください：
- ✅ `index.html` — アプリ本体

- ✅ `DISTRIBUTE.md` — 配布テンプレート

### 2. 自分で試す
`index.html` をブラウザで開いて、アプリが正常に動作するか確認してください。

`DISTRIBUTE.md` の内容に従って配布してください。

## ✨ 主な特徴

✅ **サーバー不要**
- Google アカウントやサーバー管理が一切不要です
- 個人情報がクラウドに送信されません

✅ **完全プライベート**
- すべてのデータはユーザーのブラウザに保存されます
- あなたが管理する必要がありません

✅ **シンプル配布**
- HTMLファイル1つをダウンロードするだけ
- 難しいセットアップは不要です

✅ **オフライン対応**
- インターネット接続がなくても動作します

## 🔧 アプリの主な機能

### 基本機能
- **スタンプ帳**：10マスの記録ボード
- **スタンプ選択**：4つのカテゴリから標準スタンプを選択
- **カスタム絵文字**：好きな絵文字をスタンプとして追加

### 保存方式
- **localStorage 使用**：ブラウザのデータベースに保存
- **自動保存**：操作するたびに自動的に保存されます

### データの永続性
- ブラウザのキャッシュが削除されるまで保存されます
- ブラウザを再起動してもデータは消えません
- ただし、ブラウザのキャッシュクリアやアンインストールで削除される可能性があります

## 📱 ホーム画面への追加方法

ユーザーが簡単にアプリを起動できるよう、ホーム画面に追加できます：

- **iPhone**：Safari で開く → 下部「共有」 → 「ホーム画面に追加」
- **Android**：Chrome で開く → メニュー「⋯」 → 「アプリをインストール」または「ホーム画面に追加」

詳しくは `GUIDE.md` の「ホーム画面に追加する」セクションを参照してください。

## ⚠️ 注意事項

### ユーザーへの周知項目
以下の点をユーザーに十分に説明してください：

1. **データはローカル保存のため、削除される可能性がある**
   - ブラウザキャッシュクリアで消える可能性
   - 重要なデータはスクリーンショット保存推奨

2. **デバイス間でのデータ共有なし**
   - スマホで使ったデータはパソコンでは見えません
   - 別のブラウザでも見えません

3. **インターネット接続不要**
   - ただしホーム画面追加時は接続が必要な場合があります

4. **著作物・他人の写真について**
   - 個人利用の範囲内での利用をお願いします
   - 著作権に注意してください

## 🐛 トラブルシューティング

### データが消えた
→ ブラウザのキャッシュが削除された可能性があります。重要なデータはスクリーンショット保存をお勧めします。

### 別のデバイスで見えない
→ データは各デバイスのブラウザに独立して保存されます。デバイス間での自動同期はありません。

### ファイルが開かない
→ ブラウザで開いてください（エクスプローラーのダブルクリックではなく）。
