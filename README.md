# 「がんばった すたんぷ」 ご使用方法

## 📥 セットアップ

### 1. ファイルの保存
**`index.html`** をダウンロードして、パソコン / スマホに保存してください。

### 2. ブラウザで開く
- **パソコン**：保存したファイルをブラウザにドラッグ＆ドロップ、または右クリック→「プログラムから開く」→ブラウザ選択
- **スマホ**：ファイルアプリで見つけて、ブラウザで開く

これでアプリが起動します！

---

## 🏠 ホーム画面に追加する（スマホ推奨）

毎回ファイルを開く手間を省くため、ホーム画面に「アイコン」として追加できます。

### iPhone の場合

1. Safari でアプリを開いた状態
2. 下部の「共有」ボタン（矢印↗のマーク）をタップ
3. 「ホーム画面に追加」をタップ
4. 名前を「がんばった すたんぷ」に（初期設定のままでもOK）
5. 「追加」をタップ

ホーム画面にアイコンが追加されます。次からはそこからワンタップで起動！

### Android の場合

1. Chrome でアプリを開いた状態
2. 右上の「⋯」（メニュー）をタップ
3. 「アプリをインストール」または「ホーム画面に追加」をタップ
4. 「インストール」をタップ

ホーム画面にアイコンが追加されます。

## ✨ 使い方

### スタンプを押す
1. 空いているマスをタップ
2. 好きなスタンプを選ぶ → タップ
3. スタンプが押される

### リセット（スタンプを消す）
1. 押したスタンプをタップ
2. 「このスタンプをリセットしますか？」と聞かれたら「OK」をタップ

### スタンプを追加する

#### 絵文字を追加する場合
1. スタンプ選択画面で「＋ じぶんのスタンプを追加」をタップ
2. 好きな絵文字を入力（例：⭐ 🎉 💖）
3. プレビュー欄に絵文字が表示される
4. チェックボックスにチェック
5. 「追加する」をタップ

#### 写真を追加する場合
1. スタンプ選択画面で「＋ じぶんのスタンプを追加」をタップ
2. 「📁 写真をえらぶ」をタップ
3. スマホの写真アプリから好きな写真を選択
4. プレビュー欄に選んだ写真が表示される
5. チェックボックスにチェック
6. 「追加する」をタップ

追加した絵文字・写真は「オリジナル」タブに保存されます。

## ⚠️ 注意事項

- **データはあなたのスマホ/パソコンに保存されます**  
  クラウドに送信されることはありません
  
- **ブラウザのキャッシュを削除するとデータが消えます**  
  重要なデータの場合はスクリーンショットを取っておくことをおすすめします

- **別のブラウザで開くとデータが見えません**  
  同じブラウザで開き直してください

- **デバイスを変えると見えません**  
  スマホで使っているデータはパソコンでは見えません

## 📸 写真スタンプについて

- **個人利用の範囲内で使用してください**  
  ご自身の写真か、掲載の許可を得た写真のみをお使いください

- **他人の写真・著作物は使用しないでください**  
  特にお子さまが写った写真をアップロードする場合は、保護者の同意が必要です

- **容量に注意**  
  高解像度の写真を大量に追加するとアプリが遅くなる可能性があります  
  その場合は写真を削除するか、別のブラウザで新規に始めてください

## 💡 よくある質問

**Q. データは何日保存されますか？**  
A. ブラウザのキャッシュが削除されるまで保存されます。定期的にスクリーンショットを取っておくと安心です。

**Q. 他の人と共有できますか？**  
A. HTMLファイル自体は共有できますが、データは各自のブラウザに独立して保存されます。同じファイルを開いても、相手のデータは見えません。

**Q. オフラインで使えますか？**  
A. はい、インターネット接続不要です。ダウンロードしたファイルをオフラインで開いても動作します。
